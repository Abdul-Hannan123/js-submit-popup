# 🎉 Popup Notification

A simple and interactive **Popup Notification** built using HTML, CSS, and JavaScript. When the user clicks the **Show** button, a success popup appears with a smooth animation. Clicking the **OK** button closes the popup.

---

## 🚀 Features

- 🎉 Show popup notification on button click
- ✅ Success message with a checkmark icon
- ✨ Smooth popup animation
- ❌ Close the popup by clicking the OK button
- 🎨 Clean and modern user interface
- 🌈 Attractive background and success-themed design
- 📱 Responsive layout for different screen sizes
- ⚡ Lightweight and easy to use
