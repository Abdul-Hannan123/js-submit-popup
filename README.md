# Interactive Popup UI

A simple popup modal project built using HTML, CSS, and JavaScript.

## 📌 Project Description

This project demonstrates how to create a popup modal that appears when a user clicks the **Submit** button and disappears when the user clicks **OK**.

It is a beginner-friendly project to understand DOM manipulation and event handling in JavaScript.

---

## 🚀 Features

- Clean and simple UI
- Popup appears on Submit button click
- Popup disappears on OK button click
- Smooth and interactive user experience
- Beginner-friendly JavaScript logic

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
